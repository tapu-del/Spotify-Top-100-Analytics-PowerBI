# Spotify-Top-100-Analytics-PowerBI
# 🎵 Global Spotify Top 100 - Music Analytics Dashboard

## About the Project
This project is an interactive Power BI dashboard built to analyze the most streamed songs of all time. I designed it with a custom dark and neon-green theme to match the Spotify brand.

## Tools & Skills Used
* Power BI Desktop
* Data Visualization
* Custom UI/UX Design (Dark Theme)
* Interactive Filtering (Slicers)

## Key Insights Analyzed
* **KPI Cards:** Tracked Total Streams (Billions), Total Songs, and Average BPM.
* **Artist Dominance:** A bar chart showing which artists have the most songs in the Top 100 (Taylor Swift leads!).
* **Trends Over Time:** A line chart showing how music streams have grown by release year.
* **Genre & Country:** A donut chart for top artist countries and a slicer to filter by music genre.
